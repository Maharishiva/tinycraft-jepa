# Visual review of fixed red-cube exports

All four conditions, all three predetermined scenes, all five rows, and all sixteen future frames were inspected via complete contact sheets. Scene-0 publication filmstrips were also viewed at full annotation size. This is a qualitative inspection; numerical results remain in the separate evaluation ledger.

- **Gray frame / still:** Real-frame JEPA reconstructions retain a sharply localized cube while suppressing independently redrawn texture. JEPA predictions often follow the cube, but scenes 1 and 2 contain later positional errors and artifacts. The first scene should not be described as representative proof of uniformly accurate long rollouts. Flow keeps a coherent cube and closely follows the recorded motion in these three deterministic-motion windows.
- **Gray frame / wind:** All three JEPA real-frame rows show faint/diffuse red evidence rather than a clean cube. The forecast row has strong colored texture artifacts. Flow real-frame reconstructions retain the cube, and each sampled future remains a coherent red-cube trajectory. The diagnostic decoder does not establish information-theoretic absence; its behavior is consistent with the independently measured poor state readout.
- **Gray episode / wind:** JEPA real-frame reconstructions retain a localized cube, with some blur. Forecasts deteriorate through displacement, fading, duplication, or loss of the red object. Flow samples maintain a more coherent single cube, although their realized trajectories differ from the particular recorded wind sample and some approach a border. This is a useful visible representation-versus-forecast distinction, not a proof that conditional averaging caused the errors or that a controller succeeds.
- **Gate, JEPA model seed 0:** Both real-frame reconstructions preserve the moving white wall. JEPA forecasts often omit it and also lose the cube in the third example; the second example briefly produces a wall fragment. Flow samples preserve a moving wall and one possible gap. The wall common to both gap outcomes should not disappear under an ideal conditional-mean explanation, so this image is a learned forecast failure, not evidence that averaging alone explains the wall loss. The new gate control study uses JEPA model seed 1; these seed-0 figures must not be presented as that policy's world model.

The raw RGB, latent packets, and individual PNG values are unchanged. Annotation-only colors now match the manuscript: JEPA `#CD663E`, flow `#7860A5`, real `#087E83`, navy `#17324D`. Filmstrip footers and browser metadata explicitly give both model seeds and eight flow evaluations per visual forecast step. Control compute is reported separately.

Mechanical verification passed: all 1,056 exported native-resolution images exactly match their packet arrays; every stored array hash and both input/output packet hashes match; outgoing/incoming action alignment is correct; recorded positions obey recorded moves plus wind; no selected window crosses a reset; public and direct context encoders have exactly zero numerical difference in all four cases. Exact prepare/export source snapshots are retained, and annotation rendering has its own source hash. See `redcube_story_export_verification.json`.
