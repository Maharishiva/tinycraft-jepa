## Question and claim boundary

Can the existing recurrent PPO recipe learn from native rendered observations when it receives exact environment transitions and true task signals, at either of the two already selected training packages? This reference separates a failure of the tested latent control systems from an across-the-board failure of these PPO budgets. It does **not** isolate encoder information from policy architecture. The original pixel CNN has different capacity and spatial inductive bias from the latent MLP and native-grid torsos. A successful pixel result cannot establish that the frozen encoder discarded necessary information; an unsuccessful result cannot establish that the environment is unlearnable. Existing longer-budget real-pixel training is a separate reference, not an additional seed in this matrix.

The controller is the original `studies.stoch.rl.AC(obs="pixels")`: three original Impala blocks, native 63 × 63 RGB input, original normalization by 255, 256-dimensional embedding, 128-dimensional GRU, original actor and HL-Gauss critic. The parameter count is recorded in every config and final artifact. `dim=11907` records 63 × 63 × 3 input coordinates in the saved policy; this argument is unused in the pixel constructor's layer dimensions and computation. Equality to the original default-dim constructor is checked before launch. No image resizing, handcrafted feature, position input, latent amplification, reward shaping, clipping, decoder, world-model encoder, predictor, or learned reward/done head is used. The policy receives only raw RGB, its previous action, and its own recurrent memory. Simulator state is used only to initialize and advance the transition process.
