\subsubsection*{Reproducibility statement}
All environments, models, policies and evaluators are released with the code. Every reported
policy number is a final checkpoint evaluated on stored keys; the budgets are enforced by the
training scripts, which refuse other values. Model, data and source hashes are written next to
every run. \texttt{AUDIT.md} in the repository lists, with file and line references, where each
safeguard lives and which historical numbers it does not cover.

\subsubsection*{Use of large language models}
Language-model coding agents wrote most of the experiment harness and earlier drafts of this
text under the authors' direction; the authors specified the protocols, audited the code and
results, and are responsible for every claim.
